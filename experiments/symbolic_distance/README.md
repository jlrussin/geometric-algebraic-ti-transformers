# symbolic_distance

**Question.** After finetuning on one fixed ordering, how does accuracy depend
on symbolic distance and on the number of reasoning steps in the IWL and ICL
tests?

**Delta from base.** None; the canonical finetuning configuration (one ordering,
replay 0.1, learning rate 0.0001) on the canonical pretrained network.

**Axes.** 10 seeds.

**Feeds.** The figure "Symbolic distance effects (SDE)"; the appendix figure
"Additional symbolic-distance results".
